ZeroDazed AdvertBillboards optional support
===========================================

Config option:
    Config.ZeroDazedAdvertBillboards.Enabled = true

When enabled, the Business Creator offers:
    prop_forsale_sign_fs
    zero_advertisement_small
    zero_advertisement_large

MODEL REPLACEMENT
-----------------
If you have the customised compiled model named:
    zero_advertisement_small.ydr

place/store that replacement in this install/advertbillboards folder, then copy it over the original file in your ZeroDazed AdvertBillboards resource:
    advertbillboards/stream/zero_advertisement_small.ydr

Always back up the original YDR first.

business_center_for_sale_reference.png is the Business Center for-sale artwork reference. A compiled .ydr is not fabricated by this Lua resource; use your actual/custom ZeroDazed model replacement.
